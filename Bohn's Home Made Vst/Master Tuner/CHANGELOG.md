# Master Tuner — Changelog

All notable changes to Master Tuner are logged here. Newest first.

## [0.1.0] — 2026-07-17
- **First working browser prototype** (`master-tuner.html`).
- Retune from any source Hz to any target Hz; presets for 432, 440, 444, 415 (Baroque), 528, 396.
- Live ratio / cents / semitones readout.
- Two engines: Varispeed (tape, exact) and Keep-tempo (OLA, beta).
- Mono toggle; A/B playback; WAV export.
- In-DAW note: exact Shifter cents shown for artifact-free retuning in Ableton.
- Status: 🔊 browser prototype working.
